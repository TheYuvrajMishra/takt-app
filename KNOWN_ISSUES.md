- [watch] Store mutations are not serialized: two async ops interleaving across awaits can each work from a stale template snapshot (e.g. an addBlock landing mid-split could be dropped by the split's final set). Windows are tiny (awaits are single sqlite writes); a mutation queue would be the full fix. Same class: undo/redo persist via persistSnapshot (Promise.all of five per-table transactions, full-table completion rewrite) — a crash mid-undo or a Done tap during its awaits can leave state inconsistent.
- [watch] Undo batches are a global depth counter: a Done tap landing mid-batch joins the batch's single undo entry (undoing the gesture also undoes the Done). undo()/redo() refuse to run while a batch is open, so the batch itself cannot be stranded, but the interleave is possible in a millisecond window.
