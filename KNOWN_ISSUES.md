- [resolved 2026-11-10, device crash reported by Yuvraj] Calendar BlockCard crashed on first touch: `com.facebook.jni.CppException: [Worklets] Tried to synchronously call a Remote Function. Called "anonymous" on the UI Runtime.` Root cause: BlockCard's gesture callbacks + useAnimatedStyle are worklets, but the code reached into the `props` object from inside them (`runOnJS(props.onDragStart)`, `opacity: props.dragging ...`). `props` holds functions, so the Worklets runtime treats it as a remote object and any access from a worklet throws — the anonymous function in the message was the inline `onInteractionStart={() => setScrollEnabled(false)}` passed from calendar.tsx, the first callback the Pan gesture fires. BlockCard was the only gesture component with this pattern (Dock/RadialMenu/Sheet all destructure first). Fix: every value a worklet needs is destructured at the top of the component (callbacks, height/hourHeight, block id/startMin/durationMin as primitives); `dragging` is mirrored into a shared value synced by useEffect and read in useAnimatedStyle. Guarded by src/lib/__tests__/blockCardWorklet.test.ts (reads the source via ?raw, fails if any `props.` reappears in the gesture/useAnimatedStyle region; negative-tested by reintroducing the old line). Tests 138 → 141, tsc clean, expo export OK.
